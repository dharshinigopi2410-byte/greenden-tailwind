# 🌿 GreenDen - Plant Shopping Website

## About the Project
GreenDen is a responsive plant shopping website built using HTML and Tailwind CSS. It provides a simple and attractive interface for users to explore plants and gardening products.

## Features
- Responsive website design
- Attractive home page
- Plant product sections
- Navigation menu
- Clean and simple user interface

## Technologies Used
- HTML5
- CSS3
- Tailwind CSS

## Project Structure
- `index.html` – Main webpage
- `images/` – Website images
- `README.md` – Project documentation

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
